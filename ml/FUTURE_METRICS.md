## 1. 🧤 Воротарська статистика (`stat_type="keeper"`)

Дозволяє оцінити надійність захисту та голкіпера кожної команди.

- **`SoTA`** (_Shots on Target Against_) — Кількість ударів у площину воріт команди від суперника.
- **`Saves`** — Кількість сейвів воротаря.
- **`Save%`** — Відсоток відбитих ударів.
- **`CS`** (_Clean Sheets_) — Кількість "сухих" матчів.
- **`PSxG`** (_Post-Shot Expected Goals_) — Очікувані голи після удару. Вимірює якість ударів суперника та складність сейвів для воротаря.

```python
# Приклад код для додавання в 1_extract_data.py:
keeper_stats = fbref.read_team_match_stats(stat_type="keeper")
keeper_stats.to_csv("raw_keeper_stats.csv")
```

## 2. 🟨 Дисципліна та фізична боротьба (`stat_type="misc"`)

Дозволяє оцінити агресивність гри, кількість фолів та боротьбу на полі.

- **`CrdY`** / **`CrdR`** — Жовті та червоні картки.
- **`Fls`** (_Fouls_) — Кількість здійснених фолів.
- **`Fld`** (_Fouled_) — Кількість фолів, зароблених на команді.
- **`TklW`** (_Tackles Won_) — Виграні відбори м'яча.
- **`Int`** (_Interceptions_) — Перехоплення.
- **`Recov`** (_Recoveries_) — Повернення м'яча під контроль.
- **`Won`** / **`Lost`** (_Aerial Duels_) — Виграні та програні верхові єдиноборства.

```python
# Приклад код для додавання в 1_extract_data.py:
misc_stats = fbref.read_team_match_stats(stat_type="misc")
misc_stats.to_csv("raw_misc_stats.csv")
```

## 3. 🎯 Додаткові фічі з розкладу (`stat_type="schedule"`)

У вже наявному файлі `raw_schedule.csv` також є додаткові корисні поля:

- **`attendance`** — Кількість глядачів на стадіоні.
- **`referee`** — Головний арбітр матчу (деякі арбітри дають більше карток чи пенальті).

GF / GA — Забиті та пропущені голи.

 ⚽ stat_type="shooting" (Додали в оновлений скрипт)
